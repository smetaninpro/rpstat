# Портал статистики и обучения

Веб-приложение для работы с кадровыми данными, материалами, отчетностью и экзаменационным тестированием.

## Запуск

1. Создайте `.env` на основе `.env.example`.
2. Укажите параметры PostgreSQL, `SESSION_SECRET`, `COLLECTOR_SHARED_SECRET` и прочие значения окружения.
3. Запустите сервисы: `docker compose up -d --build`.
4. Миграции применяются при старте backend.
5. Откройте портал по адресу `http://127.0.0.1:3000`.

## Экзамен

Страница экзамена: `/testing`.

- Допуск проверяется по имени, фамилии и номеру паспорта формата `999-999`.
- Продолжительность ответа на вопрос: 30 секунд.
- При новой попытке вопросы и варианты ответов перемешиваются.
- Лимит для стандартного допуска: три попытки.
- Отчет по попыткам: `/testing/report`.

## Discord-бот

Интеграция с Discord работает через приложение-бота и официальный REST API Discord.

- В `.env` должны быть заданы `DISCORD_BOT_TOKEN` и `COLLECTOR_SHARED_SECRET`.
- Боту предоставляются права только на необходимые каналы.
- Сбор выполняется через `GET /channels/{channel.id}/messages`.
- Бот не отправляет сообщения, реакции, личные сообщения и не изменяет данные Discord.
- Обработка запускается только вручную по созданной задаче.

После создания задачи сканирования запустите бота:

```bash
docker compose run --rm discord-bot
```

Контейнер обрабатывает одну ожидающую задачу и завершает работу. Ограничения по периоду и количеству сообщений задаются при создании задачи.

## Эксплуатация

- PostgreSQL не публикуется наружу.
- Backend и frontend доступны только во внутренней Docker-сети; публичный HTTPS обеспечивает Caddy.
- Не публикуйте `/api/internal/*` через прокси.
- Бэкап базы: `scripts/backup-db.sh`; восстановление: `scripts/restore-db.sh backups/<файл>.sql`.
